
# SQL Server to AWS RDS Migration Lab

This lab simulates a real-world migration of a local SQL Server Express database to AWS RDS SQL Server using infrastructure-as-code (CloudFormation), AWS Client VPN, and AWS Database Migration Service (DMS).

## Key Concepts Covered
- AWS VPC Design with Private/Public Subnets
- SQL Server RDS Deployment via CloudFormation
- AWS Client VPN Configuration using Easy-RSA Certificates
- Local SQL Server Express Setup & AdventureWorks Sample DB
- Data Migration to RDS using AWS DMS
- Troubleshooting Networking & Connectivity
